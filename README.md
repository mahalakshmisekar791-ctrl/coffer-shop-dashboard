# coffer-shop- sale -dashboard


# Project Introduction

This project involves creating an interactive Excel dashboard to analyze and visualize coffee shop sales data. The goal is to provide clear business insights into daily sales performance, product popularity, and customer purchasing trends to support data-driven decisions.

# Domain

Retail / Sales Analytics / Business Intelligence

# Objective

* To design a dynamic and visually appealing dashboard that helps track key performance indicators (KPIs) such as:

* Total sales and profit trends

* Best-selling coffee products

* Sales by location and time period

* Customer purchase behavior

# Skills Takeaway

* Data cleaning and preprocessing in Excel

* Pivot Tables and Pivot Charts

* Dashboard creation using slicers, bar, and charts

* Data visualization and storytelling

* KPI design and formatting for business reporting

# Technology / Tools Used

Microsoft Excel (Pivot Tables, Charts, Slicers, Conditional Formatting)

* Data Visualization Techniques

* Basic Data Analysis & Dashboard Design

# Key Insights (Example)

* Latte and Cappuccino were the top-selling beverages.

* The Downtown branch generated the highest revenue.
